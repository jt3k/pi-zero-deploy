# Proposal

## Why

Сейчас в проекте нет исполняемой точки входа: невозможно запустить `pizdeploy` в терминале macOS и получить какой-либо результат. Нужна минимальная локальная CLI-утилита, которая работает как «обёртка» над Bun.js и служит стабильной точкой роста для всей будущей логики деплоя.

## What Changes

- Появляется консольная команда `pizdeploy`, доступная в PATH пользователя (macOS, zsh/bash).
- При запуске `pizdeploy` под капотом стартует рантайм Bun.js, который исполняет локальный скрипт утилиты.
- Скрипт утилиты выводит в stdout строку `worked` и завершается с кодом 0.
- Добавляется инфраструктура Bun-проекта (`package.json` с `bin`, исходник скрипта) и способ установки команды в PATH (глобальная ссылка через `bun link` / `npm link` либо симлинк в `~/.local/bin`).

## Capabilities

### New Capabilities

- `cli-command`: Поведение запуска утилиты из консоли — регистрация команды `pizdeploy`, делегирование исполнения рантайму Bun.js и формирование вывода в терминале пользователя.

## Impact
