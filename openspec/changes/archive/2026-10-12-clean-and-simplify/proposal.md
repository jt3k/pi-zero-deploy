# Proposal

## Why

Текущее состояние репозитория содержит незавершённые артефакты отладки (`.probe/`, `.probe.ts`), код в `src/index.ts` переусложнён, содержит ошибки и проваливает 23 из 25 тестов в `test/cli.test.ts`. В репозитории отсутствует `.gitignore`, а основная спецификация проекта `cli-command` всё ещё описывает устаревшую заглушку (`worked`), тогда как утилита должна выполнять реальное удалённое подключение по SSH. Необходимо навести чистоту в репозитории, упростить реализацию `src/index.ts` и гарантировать корректное прохождение всех проверок.

## What Changes

- **Наведение порядка в репозитории:**
  - Удаление временных файлов отладки `.probe.ts` и каталога `.probe/`.
  - Добавление файла `.gitignore` для исключения служебных файлов macOS (`.DS_Store`), зависимостей (`node_modules`) и временных каталогов.
- **Упрощение и исправление кода CLI (`src/index.ts`):**
  - **BREAKING** Замена устаревшей заглушки `worked` на реальное выполнение удалённой команды по SSH, выводящей `pwd: <текущий рабочий каталог>` (`echo 'pwd: <cwd>'`).
  - **BREAKING** Реализация строгого и чистого разбора аргументов командной строки: поддержка флага `--ssh <user@host>` и `--ssh=<user@host>`. Неизвестные аргументы или флаг `--ssh` без значения завершаются с кодом 2 и кратким сообщением usage в stderr. Никакой лишней валидации формата адреса не выполняется.
  - Определение адреса хоста по лаконичной цепочке: флаг `--ssh` → поле `pizdeploy.ssh` в `package.json` текущего каталога (`process.cwd()`) → значение по умолчанию `pi@zero.local`.
  - Безопасное экранирование локального рабочего каталога при формировании удалённой команды в одинарных кавычках POSIX (`'\''`).
  - Вызов системного OpenSSH через Bun с опциями `-o BatchMode=yes -o ConnectTimeout=3`, прозрачный проброс вывода и кода возврата.
  - Обработка ошибки отсутствия `ssh` в `PATH` с кодом 127 и информативным сообщением в stderr.
- **Верификация и документация:**
  - Актуализация `test/cli.test.ts` (удаление лишних проверок формата адреса) и прохождение 100% тестов `bun test`.
  - Обновление `README.md` с описанием поведения, настроек SSH-ключей и кодов возврата.

## Capabilities

### New Capabilities

- `remote-exec`: Удалённое выполнение команды по SSH на целевом хосте — разрешение адреса хоста (флаг → `package.json` текущего каталога → `pi@zero.local`), безопасное экранирование `process.cwd()`, выполнение системного ssh и проброс вывода/кодов возврата.

### Modified Capabilities

- `cli-command`: Удаление требований о заглушке `worked` и игнорировании аргументов; добавление требований разбора флага `--ssh`, обработки ошибок использования с кодом 2 и прямого исполнения через шебанг Bun.

## Impact

- **Файловая структура:** удаление `.probe/`, `.probe.ts`, удаление обёртки `bin/pizdeploy`; создание `.gitignore`.
- **Код:** ультракомпактная реализация `src/index.ts` (< 35 строк) без сторонних зависимостей.
- **Тесты:** обеспечение прохождения полного набора интеграционных тестов в `test/cli.test.ts`.
- **Документация:** актуализация `README.md`.
- **Внешние зависимости:** дополнительных npm-зависимостей не добавляется, требуется наличие системного клиента OpenSSH.
