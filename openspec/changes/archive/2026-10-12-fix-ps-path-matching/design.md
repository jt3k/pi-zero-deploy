# Design

## Context

В функции `handlePs` в `src/index.ts` выполняется удалённый python-скрипт, собирающий информацию о запущенных процессах. Скрипт сопоставляет рабочий каталог процесса `cwd` с каталогом каждого проекта `p`:
```python
cwd = os.path.realpath(f"/proc/{pid}/cwd")
if cwd.startswith(p):
```
Без замыкающего разделителя пути (`/`) префиксная проверка даёт ложные совпадения для проектов, чьи имена являются префиксами других проектов (например, `/home/pi/projects/pi-zero-deploy` ошибочно захватывает процессы из `/home/pi/projects/pi-zero-deploy-lite`).

Кроме того, на сервере `pi@zero.local` остался устаревший процесс `node` (PID 11538), запущенный через `bash` в обход systemd, который виден в выводе `ps` для `pi-zero-deploy-lite`.

## Goals / Non-Goals

**Goals:**
- Обеспечить строгое сопоставление путей с учётом границы каталога (`cwd == p or cwd.startswith(p + "/")`).
- Добавить тесты в `test/cli.test.ts`, симулирующие проекты с совпадающими префиксами имён (`app` и `app-extra`).
- Завершить устаревший фоновый процесс на хосте `zero.local` и убедиться в чистоте вывода `pizdeploy ps`.

**Non-Goals:**
- Изменение прав доступа или перевод `ps` на `sudo`.
- Изменение структуры конвейера деплоя или systemd-шаблонов.

## Decisions

### 1. Строгая проверка границы каталога через слэш
- **Выбор:** `if cwd == p or cwd.startswith(p + "/"):`
- **Обоснование:** Простейшая и максимально производительная проверка без дополнительных вызовов файловой системы или сложных регулярных выражений.
- **Альтернативы:** Использование `os.path.commonpath` — медленнее и требует обработки исключений при разных корнях путей.

### 2. Безопасное завершение устаревшего процесса на Pi
- **Выбор:** Отправка команды `kill` по SSH для PID 11538 / 11537 с предварительной проверкой команды процесса.
- **Обоснование:** Очищает висящий процесс, освобождает порт 3999 и восстанавливает актуальное отображение состояния `inactive` для остановленной службы.

## Risks / Trade-offs

- **[Риск]** PID процесса на хосте мог измениться после перезагрузки.  
  → **Смягчение:** Проверять команду процесса перед отправкой SIGTERM (`pkill -f "PORT=3999 node server.js"` или проверка PID).
