# Spec Delta

## MODIFIED Requirements

### Requirement: Сбор активных слушающих процессов и служб systemd

Система SHALL анализировать слушающие сокеты через `ss -tlpn`, строго сопоставлять PID процессов с границами рабочей директории проектов (`cwd == project_dir` или `cwd` начинается с `project_dir/`), исключая ложное срабатывание для проектов с префиксными именами, и определять имя службы systemd через `/proc/<pid>/cgroup` без использования прав суперпользователя `sudo`.

#### Scenario: Сопоставление запущенного процесса с проектом
- **WHEN** процесс слушает входящие соединения на локальном порту
- **AND** его рабочая директория `/proc/<pid>/cwd` совпадает с каталогом проекта `/home/pi/projects/<name>` или является его поддиректорией
- **THEN** статус проекта помечается как `running`
- **AND** фиксируются его сетевой порт, идентификатор процесса PID и имя службы systemd из cgroup

#### Scenario: Изоляция проектов с похожими префиксами имён
- **WHEN** в `/home/pi/projects` существуют проекты с префиксными именами (например, `app` и `app-worker`)
- **AND** запущен процесс, чей рабочий каталог находится внутри `app-worker`
- **THEN** проект `app` не сопоставляется с этим процессом и не перехватывает его статус

#### Scenario: Проект не запущен
- **WHEN** ни один слушающий процесс не имеет рабочей директории внутри проекта
- **THEN** статус проекта помечается как `inactive`
- **AND** порт, PID и служба помечаются как отсутствующие (`-`)
