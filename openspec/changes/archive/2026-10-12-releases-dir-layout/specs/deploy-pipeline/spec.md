# Spec Delta

## Purpose

Определяет конвейер безопасного развёртывания релизов через буферную директорию staging (incoming), распаковку в постоянное хранилище релизов (releases), атомарное переключение активной версии (current) и ротацию версий.

## ADDED Requirements

### Requirement: Доставка архива через временный буфер incoming

Система SHALL загружать собранный архив `dist.tar.gz` (и юнит при наличии) во временную буферную директорию `~/projects/<name>/incoming/`, изолируя процесс передачи от каталога релизов.

#### Scenario: Успешная загрузка архива
- **WHEN** выполняется передача файлов релиза на удалённый хост
- **THEN** архив копируется по пути `~/projects/<name>/incoming/dist.tar.gz`
- **AND** в каталоге `releases` не создаётся незавершённых или повреждённых директорий

### Requirement: Распаковка в постоянный каталог releases

Система SHALL распаковывать полученный архив из `incoming/` в постоянную директорию релиза `~/projects/<name>/releases/<name>_<hash5>` и удалять временный архив из `incoming/`.

#### Scenario: Распаковка релиза
- **WHEN** архив полностью доставлен на хост
- **THEN** создается директория `~/projects/<name>/releases/<name>_<hash5>`
- **AND** архив распаковывается внутрь этой директории
- **AND** временный файл `dist.tar.gz` в `incoming/` удаляется

### Requirement: Атомарное переключение симлинка current

Система SHALL атомарно переключать симлинк `current` на директорию нового релиза в `releases/<name>_<hash5>`.

#### Scenario: Переключение симлинка
- **WHEN** файлы релиза распакованы в `releases/<name>_<hash5>`
- **THEN** создается временный симлинк `current_tmp` с таргетом `releases/<name>_<hash5>`
- **AND** выполняется атомарная замена `current` через `mv -fT`

### Requirement: Ротация релизов в директории releases

Система SHALL выполнять ротацию старых версий в директории `releases/`, сохраняя последние 3 релиза и удаляя более старые.

#### Scenario: Очистка старых версий
- **WHEN** новый релиз успешно активирован
- **THEN** список директорий в `releases/` сортируется по имени
- **AND** удаляются все версии, кроме 3 самых последних
