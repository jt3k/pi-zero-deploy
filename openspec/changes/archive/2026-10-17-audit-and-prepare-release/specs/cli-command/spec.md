# Spec Delta

## ADDED Requirements

### Requirement: Справка и версия утилиты

Система SHALL поддерживать флаги `--help` (`-h`) и `--version` (`-v`), выводя информативное руководство или версию с кодом завершения 0 без вызова удалённых хостов или сборки.

#### Scenario: Запрос справки

- **WHEN** пользователь выполняет `pizdeploy --help` или `pizdeploy -h`
- **THEN** в stdout выводится руководство по командам и флагам
- **AND** код возврата равен 0

#### Scenario: Запрос версии

- **WHEN** пользователь выполняет `pizdeploy --version` или `pizdeploy -v`
- **THEN** в stdout выводится текущая версия утилиты
- **AND** код возврата равен 0

### Requirement: Валидация входных параметров CLI

Система SHALL проверять корректность и безопасность позиционных аргументов команд (`name`, `service`) и флагов (`--ssh`), отвергая значения со спецсимволами командных оболочек и попытками внедрения аргументов.

#### Scenario: Недопустимые символы в имени службы

- **WHEN** пользователь передаёт имя службы или проекта, содержащее символы инъекций (`;`, `&`, `|`, кавычки, пробелы, переводы строк)
- **THEN** утилита прерывает работу с сообщением об ошибке валидации
- **AND** код возврата равен 2

#### Scenario: Недопустимое значение флага --ssh

- **WHEN** аргумент `--ssh` начинается с символа `-`
- **THEN** утилита отклоняет его как недопустимый адрес хоста во избежание внедрения аргументов ssh
- **AND** код возврата равен 2

## MODIFIED Requirements

### Requirement: Ошибки использования завершаются кодом 2

Система SHALL завершаться с кодом возврата 2 и сообщением в stderr, содержащим актуальную подсказку по использованию `usage: pizdeploy [init|ps|start|stop|restart|status|logs|disable|remove|rm] [name] [--ssh <user@host>] [--dry-run]`, при неизвестном аргументе или отсутствии обязательного значения после флага `--ssh`, исключая стандартные флаги справки и версии (`--help`, `-h`, `--version`, `-v`).

#### Scenario: Неизвестный аргумент

- **WHEN** пользователь выполняет `pizdeploy --unknown` или `pizdeploy unknown`
- **THEN** в stderr появляется сообщение, содержащее актуальную строку usage
- **AND** stdout пуст
- **AND** код возврата равен 2

#### Scenario: --ssh без значения

- **WHEN** пользователь выполняет `pizdeploy --ssh` или `pizdeploy stop --ssh`
- **THEN** в stderr появляется сообщение, содержащее актуальную строку usage
- **AND** stdout пуст
- **AND** код возврата равен 2
