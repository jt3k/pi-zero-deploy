# Spec Delta

## ADDED Requirements

### Requirement: Безопасное формирование локального архива

Система SHALL упаковывать каталог сборки во временный файл с уникальным именем во временном каталоге ОС, предотвращая перезапись или случайное удаление пользовательских файлов `dist.tar.gz` в корне проекта.

#### Scenario: Существующий dist.tar.gz не перезаписывается

- **WHEN** в каталоге проекта уже присутствует файл `dist.tar.gz`
- **AND** пользователь выполняет деплой
- **THEN** утилита использует изолированный временный архив для передачи
- **AND** существующий пользовательский файл `dist.tar.gz` остаётся нетронутым

### Requirement: Валидация имени проекта

Система SHALL валидировать имя проекта из `package.json` (разрешены буквы, цифры, дефис, точка и подчеркивание), отклоняя попытки Path Traversal (`..`) и спецсимволы.

#### Scenario: Недопустимое имя проекта

- **WHEN** `package.json` содержит имя с недопустимыми символами или путями перехода (`../`)
- **THEN** деплой завершается с ошибкой валидации до создания каталогов и вызова удалённых команд
- **AND** код возврата равен 1
