# Spec Delta

## ADDED Requirements

### Requirement: Безопасная запись unit-файла на хосте

Система SHALL записывать сгенерированный unit-файл на целевом хосте безопасным способом, исключающим выполнение произвольного кода при наличии маркеров heredoc в шаблоне или пользовательских переменных окружения.

#### Scenario: Наличие маркера heredoc в шаблоне

- **WHEN** пользовательский шаблон `systemd-unit.service` содержит маркер `PIZDEPLOY_UNIT` или специфичные спецсимволы
- **THEN** юнит записывается на хост без выполнения команд и без разрыва тела файла
- **AND** конфигурация сохраняется в точности в `~/.config/systemd/user/<service>`
