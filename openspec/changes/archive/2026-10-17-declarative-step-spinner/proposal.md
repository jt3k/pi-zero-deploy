# Proposal

## Why

В текущей версии логирования пользователь видит результат только после завершения шага, а во время выполнения длительных операций (сборка, загрузка архива через scp, ожидание поднятия службы) нет визуальной индикации активности. Кроме того, код конвейера содержит повторяющиеся блоки замера времени. Декларативная обёртка шагов с односимвольным спиннером в стиле «змейки» (snake game) отображает текущий активный шаг в режиме реального времени и делает код конвейера лаконичным и читаемым.

## What Changes

- Добавлена декларативная функция `withStep(label, fn)` (и/или класс `StepRunner`), инкапсулирующая запуск асинхронного шага, замер времени, анимацию ожидания и форматирование результата.
- Реализован компактный односимвольный спиннер в стиле snake game, отображаемый перед названием текущего выполняющегося шага в TTY-терминале.
- По завершении шага строка спиннера атомарно перезаписывается стандартным результатом `✓ <label> [XX.XXms]` (или `✗ <label> [XX.XXms]` при ошибке).
- В неинтерактивном окружении (`!process.stdout.isTTY`, CI, тестовые пайпы) спиннер автоматически отключается, выводя результат только по завершении шага без управляющих символов перезаписи строки.
- Конвейер деплоя `src/deploy.ts` и `runStep` в `src/ssh.ts` переведены на декларативное описание шагов.
- Перевод вызовов удалённых команд `remoteExec` на неблокирующий асинхронный `Bun.spawn` вместо `Bun.spawnSync` для исключения блокировок Event Loop и обеспечения плавной анимации спиннера на длительных шагах (`daemon-reload`, включение службы).
