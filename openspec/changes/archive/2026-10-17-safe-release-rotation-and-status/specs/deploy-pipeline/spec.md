# Spec Delta

## MODIFIED Requirements

### Requirement: Ротация релизов в директории releases

Система SHALL выполнять безопасную ротацию старых версий в директории `releases/`, сохраняя последние 3 релиза и гарантированно исключая из удаления активную версию, на которую указывает симлинк `current`. Сортировка версий для ротации SHALL осуществляться по реальному времени изменения (mtime) директорий, а не по лексикографическому порядку имён. Сбой ротации не должен влиять на код возврата уже успешно выполненных шагов конвейера.

#### Scenario: Очистка старых версий

- **WHEN** новый релиз успешно активирован
- **THEN** список директорий в `releases/` упорядочивается по времени изменения (от старых к новым)
- **AND** активный релиз, на который указывает симлинк `current`, исключается из списка на удаление
- **AND** удаляются устаревшие неактивные релизы, превышающие лимит хранения в 3 версии

#### Scenario: Защита активного релиза от случайного удаления

- **WHEN** имя нового релиза лексикографически предшествует именам существующих релизов
- **AND** симлинк `current` указывает на этот новый релиз
- **THEN** этот релиз не удаляется в процессе ротации
- **AND** симлинк `current` остаётся валидным и указывает на существующую директорию

#### Scenario: Ротация не скрывает чужих ошибок

- **WHEN** любой из предшествующих шагов конвейера завершился с ненулевым кодом возврата
- **THEN** итоговый код возврата конвейера ненулевой
- **AND** сообщение об успешном развёртывании не выводится
