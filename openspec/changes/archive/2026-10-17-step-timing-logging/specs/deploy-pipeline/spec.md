# Spec Delta

## ADDED Requirements

### Requirement: Поэтапное логирование шагов конвейера с замером времени

Система SHALL выводить в stdout статус выполнения каждого успешного промежуточного шага конвейера деплоя с символом `✓`, наименованием шага и временем его выполнения в формате `[XX.XXms]` для длительностей менее 1 секунды или `[XX.XXs]` для длительностей от 1 секунды и более. При возникновении ошибки на любом шаге система SHALL выводить сообщение об ошибке в stderr и не выводить финальное подтверждение успешного развёртывания.

#### Scenario: Успешное выполнение шагов деплоя

- **WHEN** выполняется процесс деплоя
- **THEN** каждый завершённый шаг (сборка, упаковка, подготовка каталогов, передача архива, linger, распаковка, переключение current, запись юнита, daemon-reload, включение службы, верификация, ротация) выводится в stdout в формате `✓ <описание шага> [<время>]`

#### Scenario: Прерывание конвейера при сбое шага

- **WHEN** один из промежуточных шагов конвейера завершается с ненулевым кодом возврата
- **THEN** выполнение конвейера немедленно прекращается
- **AND** в stderr выводится диагностическое сообщение о сбое
- **AND** в stdout не выводится итоговое сообщение об успешном развёртывании
