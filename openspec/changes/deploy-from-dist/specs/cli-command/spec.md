# Spec Delta

## ADDED Requirements

### Requirement: Флаг --dry-run включает режим предварительного просмотра

Система SHALL принимать флаг `--dry-run` в аргументах командной строки и переводить утилиту в режим предварительного просмотра действий без выполнения изменений.

#### Scenario: Передача флага --dry-run
- **WHEN** пользователь выполняет `pizdeploy --dry-run` или `pizdeploy --dry-run --ssh pi@custom.local`
- **THEN** аргумент успешно распознается парсером аргументов командной строки
- **AND** код возврата равен 0

## MODIFIED Requirements

### Requirement: Ошибки использования завершаются кодом 2

Система SHALL завершаться с кодом возврата 2 и сообщением в stderr при неизвестном аргументе или отсутствии значения после флага `--ssh`.

#### Scenario: Неизвестный аргумент
- **WHEN** пользователь выполняет `pizdeploy --help` или `pizdeploy deploy prod`
- **THEN** в stderr появляется сообщение, содержащее `usage`
- **AND** stdout пуст
- **AND** код возврата равен 2

#### Scenario: --ssh без значения
- **WHEN** пользователь выполняет `pizdeploy --ssh`
- **THEN** в stderr появляется сообщение, содержащее `usage`
- **AND** stdout пуст
- **AND** код возврата равен 2
