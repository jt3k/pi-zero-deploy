# Spec Delta

## Purpose

Определяет полный конвейер деплоя артефактов из директории dist: локальную сборку, упаковку, расчет детерминированного хэша, изолированную доставку на Raspberry Pi, атомарное переключение текущей версии и ротацию.

## ADDED Requirements

### Requirement: Сборка и детерминированное хэширование

Скрипт SHALL запустить локальную сборку проекта, упаковать полученные артефакты в архив dist.tar.gz и вычислить уникальный 5-символьный хэш релиза на основе содержимого архива.

#### Scenario: Получение хэша из tar-архива
- **WHEN** запускается процесс деплоя
- **THEN** скрипт выполняет локальную команду `bun run build`
- **AND** упаковывает содержимое директории `dist` в архив `dist.tar.gz`
- **AND** рассчитывает криптографический хэш SHA-256 от файла `dist.tar.gz`
- **AND** берет первые 5 символов этого хэша в качестве единственного суффикса релиза `<name>_<hash_5>`

### Requirement: Изолированная доставка в incoming без timestamp

Скрипт SHALL считать имя проекта из `package.json`, отправить архив в изолированную директорию `incoming/` по пути `<name>_<hash_5>`, распаковать его и атомарно переключить работающий сервис.

#### Scenario: Развертывание релиза
- **GIVEN** локальный архив `dist.tar.gz` успешно создан и хэширован
- **WHEN** начинается фаза доставки на целевой хост
- **THEN** скрипт извлекает `<name>` из `package.json` (по умолчанию `app`)
- **AND** создает на Raspberry Pi директорию `~/projects/<name>/incoming/<name>_<hash_5>`
- **AND** передает архив `dist.tar.gz` через `scp` в созданную директорию
- **AND** распаковывает файлы на месте и удаляет архив из удаленной директории
- **AND** атомарно переключает симлинк `current` на новую директорию релиза
- **AND** перезапускает службу `sudo systemctl restart app.service`

### Requirement: Ротация релизов в incoming

Скрипт SHALL выполнять ротацию версий в директории `incoming/`, оставляя только последние 3 релиза и удаляя более старые.

#### Scenario: Удаление старых релизов
- **WHEN** новый релиз успешно развернут и симлинк переключен
- **THEN** скрипт находит все каталоги в `incoming/`, сортирует их и удаляет все, кроме 3 самых свежих версий

### Requirement: Очистка временных локальных файлов

Скрипт SHALL гарантированно удалять локальный временный архив `dist.tar.gz` после завершения или при ошибке сборки и доставки.

#### Scenario: Очистка локального архива
- **WHEN** деплой завершается успешно или с ошибкой
- **THEN** локальный файл `dist.tar.gz` отсутствует в корне проекта

### Requirement: Предварительный просмотр деплоя без мутаций

Скрипт SHALL при передаче флага `--dry-run` выводить в терминал путь целевого развертывания и планируемые действия без выполнения реальной сборки, передачи файлов и сетевых команд.

#### Scenario: Выполнение с флагом dry-run
- **WHEN** пользователь запускает команду с флагом `--dry-run`
- **THEN** скрипт не запускает `bun run build` и не создает локальный архив
- **AND** не выполняет сетевых операций с удаленным хостом
- **AND** выводит в терминал сообщение с указанием целевой директории развертывания
