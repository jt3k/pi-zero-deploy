# Spec Delta

## REMOVED Requirements

### Requirement: Удалённая команда получает текущий рабочий каталог

**Reason**: Тестовая команда `echo pwd: <cwd>` заменена на полноценный сценарий деплоя артефактов из директории dist, специфицированный в способности `dist-deploy`.

**Migration**: Утилита `pizdeploy` теперь выполняет развёртывание проекта, а не демонстрационный вывод рабочего каталога.
