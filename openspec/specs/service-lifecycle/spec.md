# service-lifecycle Specification

## Purpose

Обеспечивает удалённое управление жизненным циклом служб systemd на хосте: остановку запущенного процесса службы и отключение её автоматического запуска при старте системы.

## Requirements

### Requirement: Остановка процесса службы на удалённом хосте

Система SHALL останавливать процесс целевой службы на удалённом хосте командой `systemctl --user stop <service>` от имени подключаемого пользователя, без привилегий суперпользователя, с разрешением имени службы из аргументов командной строки или локального `package.json`.

#### Scenario: Остановка службы по явно переданному имени
- **WHEN** пользователь выполняет `pizdeploy stop my-app`
- **THEN** имя службы нормализуется до `my-app.service`
- **AND** на удалённом хосте выполняется `systemctl --user stop my-app.service`
- **AND** в консоль выводится подтверждение остановки службы

#### Scenario: Остановка службы по умолчанию из проекта
- **WHEN** пользователь выполняет `pizdeploy stop` без указания имени
- **THEN** имя службы извлекается из `package.json` (`pizdeploy.service` или `name.service`, по умолчанию `app.service`)
- **AND** на удалённом хосте выполняется `systemctl --user stop <service>`

#### Scenario: Целевая служба не найдена
- **WHEN** на удалённом хосте указанная служба отсутствует в пользовательском менеджере
- **THEN** утилита сообщает в терминале, что служба не найдена, и завершается с ненулевым кодом ошибки

#### Scenario: Остановка не требует пароля
- **WHEN** на хосте `sudo` недоступен без пароля
- **THEN** остановка службы завершается успешно

### Requirement: Отключение автозапуска службы на удалённом хосте

Система SHALL отключать автозапуск целевой службы командой `systemctl --user disable <service>` от имени подключаемого пользователя, без привилегий суперпользователя, с разрешением имени службы из аргументов командной строки или локального `package.json`.

#### Scenario: Отключение автозапуска по явно переданному имени
- **WHEN** пользователь выполняет `pizdeploy disable my-app`
- **THEN** имя службы нормализуется до `my-app.service`
- **AND** на удалённом хосте выполняется `systemctl --user disable my-app.service`
- **AND** в консоль выводится подтверждение отключения автозапуска службы

#### Scenario: Отключение автозапуска службы по умолчанию из проекта
- **WHEN** пользователь выполняет `pizdeploy disable` без указания имени
- **THEN** имя службы извлекается из `package.json` (`pizdeploy.service` или `name.service`, по умолчанию `app.service`)
- **AND** на удалённом хосте выполняется `systemctl --user disable <service>`

#### Scenario: Отключение не требует пароля
- **WHEN** на хосте `sudo` недоступен без пароля
- **THEN** отключение автозапуска завершается успешно
